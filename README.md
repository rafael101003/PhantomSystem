💻 Phantom System - Manutenção de Hardware
Status do Projeto: 🚀 Concluído / Em produção

O Phantom System é um site estático moderno e responsivo desenvolvido para uma loja especializada em prestação de serviços e manutenção de hardware (computadores, notebooks e periféricos). O objetivo principal da plataforma é apresentar os serviços oferecidos, transmitir confiança ao cliente e facilitar o contato direto com a assistência técnica.

🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as tecnologias fundamentais da web para garantir leveza, velocidade de carregamento e SEO otimizado:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, layout (Flexbox/Grid) e animações.

JavaScript (Vanilla): Manipulação do DOM para interatividade (menus, animações de scroll, etc.).

Font Awesome: Ícones modernos e intuitivos.

✨ Funcionalidades do Site
Design Responsivo: Adaptado perfeitamente para qualquer dispositivo (Celulares, Tablets e Desktops).

Seção de Serviços: Vitrine detalhada dos principais reparos (troca de peças, limpeza preventiva, montagem de PCs gamer, etc.).

Sobre Nós: Espaço dedicado à história e aos valores de transparência da Phantom System.

Formulário de Orçamento / Contato: Canal direto integrado para o cliente solicitar atendimento.

Botão Flutuante do WhatsApp: Facilitador de conversão para atendimento rápido em tempo real.

Dark Mode / Estética Phantom: Identidade visual moderna e tecnológica, inspirada no universo do hardware.

🚀 Como Executar o Projeto
Por ser um site estático, você não precisa instalar dependências pesadas. Basta clonar e abrir no seu navegador.

Pré-requisitos
Apenas um navegador web (Chrome, Edge, Firefox, Safari) instalado.
