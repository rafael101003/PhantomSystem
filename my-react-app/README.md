# 💻 Phantom System - Calculadora de Orçamentos

Aplicação web estática voltada para a apresentação e simulação de custos de serviços de assistência técnica e manutenção de hardware, integrada diretamente ao WhatsApp da empresa.

---

## 🚀 Tecnologias Utilizadas

* **React 18** + **Vite**
* **React Router DOM v6** (Navegação SPA)
* **Bootstrap 5** + **React Bootstrap Icons**
* **CSS Custom Properties** (Variáveis Globais)

---

## 🛠️ Funcionalidades

- [x] **Seleção Dinâmica de Serviços:** Cálculo automático do valor total em tempo real.
- [x] **Integração Click-to-Chat:** Redirecionamento direto com a lista formatada no WhatsApp Business.
- [x] **Totalmente Responsivo:** Design otimizado para celulares, tablets e desktops.
- [x] **Acessível (a11y):** Suporte à navegação completa por teclado e leitores de tela.
